Making the next action legible

My work covered screen layout and controls, battle interaction logic and audiovisual feedback.

Coin details were placed opposite the slots to keep selectable coins visible. Hover outlines identified input targets; sounds accompanied coin selection and lever use.

Visual state and input state

Problem

After cancellation, the visible coin and the next selectable coin could differ.

Correction

I corrected the return animation and slot order together, so the visible result and the next input stayed aligned.

Integration with the team

Preparation-phase slot clicks and input bindings were updated following a teammate’s interaction-interface refactor. The work connected UI decisions with the game’s interaction state.
