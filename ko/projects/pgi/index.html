PGI (Player-Game Interaction) 피드백 시스템 개발

가상 젠가와의 상호작용에 따라 접촉 패드를 회전시키고 손가락 쪽으로 당기는 손끝 장치입니다.

개인 프로젝트

Fusion 360 · Unity · Python / MediaPipe · Arduino

시연 보기소스 코드코드 내려받기
배경설계구현시연 보기결과

입력 방식에서 피드백으로

인터랙티브 게임 시스템 개발에서는 몸의 동작으로 조작 방식을 바꿨지만, 게임의 반응은 여전히 시각 정보에 집중되어 있었습니다. PGI는 이 경험에서 출발해 물리적 피드백으로 관심을 확장한 프로젝트입니다.

왜 젠가였는가

같은 모양의 블록도 탑에서의 위치에 따라 밀 때 느껴지는 저항이 달라집니다. 젠가는 겉모습만으로 알기 어려운 접촉 정보를 다루기에 적합한 시험 환경이었습니다. 게임 자체보다 장치와 소프트웨어의 통합에 초점을 두었습니다.

상명대학교 미래설계학점으로 전공학점을 인정받았으며, 경희대학교 Haptics and Virtual Reality Lab의 도움을 받아 진행했습니다.

패드의 방향과 와이어 장력을 나누어 제어

손끝에 모터 무게가 실리지 않도록 두 서보를 손목 밴드에 배치했습니다. 한 서보는 한 쌍의 와이어로 패드를 회전시키고, 다른 서보는 패드를 손가락 쪽으로 당깁니다. 장력이 풀리면 스프링이 패드를 복귀시킵니다.

  • 01

    손끝 기구

    출력한 마운트, 회전 레버, 스프링, 접촉 패드.

  • 02

    손목 구동부

    패드 회전과 와이어 당김을 담당하는 두 서보.

  • 03

    제어 보드

    Arduino Nano Every가 USB 시리얼로 두 서보의 각도 명령을 수신.

각기 다른 문제를 다룬 세 차례의 제작

01초기 조립

마운트, 레버, 스프링, 와이어를 결합한 첫 기구입니다. 사진 왼쪽의 빨간 장치가 초기 버전이며, 오른쪽은 이후 수정본입니다.

02패드 방향과 간격

원형 패드 축이 불필요하게 회전하는 문제에 대응해 사각 축으로 바꿨습니다. 마운트 돌출부를 제거하고 손가락과의 거리도 줄였습니다.

03손가락 측면 지지

패드를 당기면 손가락이 엄지 쪽으로 밀렸습니다. 모터 출력을 높이기보다 구조의 문제로 판단해 마운트 양측을 확장했습니다.

설계 기록과 사진으로 변경 사항을 확인할 수 있습니다. 착용감이나 힘 전달의 개선 정도를 수치로 측정하지는 않았습니다.

보이는 손과 충돌 위치를 일치시키기

초기에는 추적된 손과 블록의 위치가 맞지 않았습니다. 보관된 구현에서는 화면에 표시하는 손끝 위치를 충돌과 피드백 계산에도 함께 사용합니다. 화면상 손 크기로 깊이를 조절해 손을 카메라 쪽으로 가져오면 가상 장면 안으로 전진하게 했습니다.

이는 추정 깊이를 이용한 화면 기준 매핑입니다. 손의 실제 3차원 위치를 보정해 복원한 것은 아니며, 표시되는 21개 점은 같은 깊이에 놓입니다.

회전과 당김을 구분한 제어 상태

6월 22일 보관 코드에서는 손끝 방향으로 회전 명령을 계산하고, 설정한 각도·거리 범위 안에서 당김을 활성화합니다. 진입과 복귀 거리를 다르게 둔 히스테리시스로 단일 경계 근처에서 잦은 상태 전환이 일어나지 않도록 했습니다.

  • 당김 상태 진입손가락–블록 방향각 ≤ 90°, 표면 거리 < 0.12 Unity 단위.
  • 회전 상태 복귀표면 거리 > 0.18 Unity 단위.
  • 당김 명령 계산충돌 충격량에서 추정한 가상 접촉 힘을 서보 각도로 변환.

프로토타입 시연 기록

프로토타입으로 확인한 범위

세 차례의 하드웨어 제작과 손 추적–가상 상호작용–서보 구동의 통합까지 진행했습니다. 상호작용 구상, 기구 설계와 제작, 통합 요구사항 정의, 반복 시험을 맡았습니다. 소프트웨어 구현에는 AI의 도움을 받았습니다.

남아 있는 한계

손 방향에 따른 추적 중단, 체감 지연, 서보 떨림, 두 와이어 채널의 기계적 간섭이 남았습니다. 실제 손끝 힘의 보정과 사용자의 블록 저항 구분 능력은 평가하지 않았습니다.
