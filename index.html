I am an undergraduate in Game Design and Development at Sangmyung University. My work connects game interaction design with physical input and feedback, through two-hand motion controllers for Carrot Mart and a wearable fingertip interface for PGI (Player-Game Interaction). I am interested in how sensing and haptic feedback can support interaction with virtual objects.

Projects

PGI (Player-Game Interaction) Feedback System

Tendon-driven fingertip force feedback for a virtual Jenga scene

March–June 2026 · Individual project, Sangmyung University Future Design Program · Supported by the Haptics and Virtual Reality Lab, Kyung Hee University

Designed and integrated a fingertip pad whose orientation and pull respond to virtual contact. Three mechanical iterations connected hand tracking, a Unity scene and two servo channels.

Project page Video Implementation Code

Carrot Mart: Two-Hand Motion Controllers for a Horse-Riding Game

Carrot Mart: Short-Term Horse Rider Wanted · Interactive Game System Development

September–December 2025 · Three-person team; I proposed the project and built the controllers and input integration

Two handheld IMU controllers that present themselves as a BLE keyboard and mouse. Left-hand steering gestures drive the horse; a spin-then-throw sequence on the right hand releases the lasso. Gesture rules run on the devices.
