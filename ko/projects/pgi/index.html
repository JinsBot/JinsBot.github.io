왜 젠가를 택했나

겉보기에는 같은 젠가 블록도 밀어 보면 저항이 다를 수 있습니다. 착용 장치로 그 접촉을 전달해 보기 위해, 검지 하나로 블록을 미는 동작을 시제품의 테스트 상황으로 삼았습니다.

손끝 장치를 설계하고 제작했으며, 손 추적과 Unity의 접촉 판정을 서보 구동으로 연결했습니다.

상명대학교 미래설계학점으로 전공학점을 인정받은 개인 프로젝트입니다.
경희대학교 Haptics and Virtual Reality Lab의 지원을 받아 진행했습니다.

시제품 시연

손끝 장치의 구조와 개선 과정

손끝에 모터 무게가 실리지 않도록 서보 두 개를 손목에 배치했습니다. 하나는 패드의 방향을 조절하고, 다른 하나는 패드를 손끝 쪽으로 당깁니다. 당기는 줄이 느슨해지면 스프링이 피스톤을 원위치로 돌려놓습니다.

손동작이 패드 구동으로 이어지는 과정

  1. 손 추적MediaPipe · 랜드마크 21개
  2. 가상 접촉 계산Unity · 충격량 / 물리 스텝 시간
  3. 패드 구동Arduino · 서보 각도 2개

각도 θ는 검지 끝마디가 향하는 방향과, 손끝에서 블록 중심을 향하는 방향이 이루는 각도입니다.거리 d는 손끝에서 가장 가까운 블록 표면까지의 거리입니다. 단위는 Unity 월드 좌표를 기준으로 합니다.

접촉 상태 전환 조건

θ ≤ 90°이고 d < 0.12이면 패드를 당기기 시작합니다. d > 0.18이면 당김을 해제합니다. 진입과 해제에 다른 거리 기준을 두어 경계에서 상태가 빠르게 바뀌는 것을 줄였습니다.

패드를 당기는 동안에도 방향 갱신

패드를 당기는 동안에도 회전 명령을 계산합니다. 제어에는 시뮬레이션의 접촉 정보가 쓰이며, 실제 패드 각도나 손끝에 가해진 힘은 센서로 측정하지 않습니다.

손 좌표와 충돌 판정

초기 테스트에서는 추적한 손의 위치가 가상 블록과 어긋났습니다. 공개한 구현에서는 화면에 표시되는 손끝 좌표를 충돌 판정과 피드백 계산에 공통으로 사용합니다. 손바닥이 카메라에 크게 보일수록 깊이값을 조정해, 손을 카메라 쪽으로 내밀면 가상 장면 안에서도 앞으로 움직이도록 했습니다.

깊이를 추정해 화면 좌표를 매핑한 방식입니다. 보정된 3차원 손 위치를 복원하는 것은 아니며, 화면에 표시되는 랜드마크 21개는 같은 깊이값을 사용합니다.

회전과 당김 상태

6월 22일 코드에서는 손가락과 블록이 이루는 각도로 회전 명령을 계산합니다. 지정한 각도와 거리 조건을 충족하면 줄을 당기는 상태로 전환하며, 이때에도 회전 명령은 계속 갱신합니다. 진입과 해제에 서로 다른 거리 기준을 둬 접촉 경계에서 상태가 반복해서 바뀌는 것을 줄였습니다.

  • 당김 시작각도 ≤ 90°이며 표면까지의 거리가 0.12 Unity 단위 미만일 때.
  • 당김 해제표면까지의 거리가 0.18 Unity 단위를 초과할 때.
  • 당김량 계산Unity에서 충돌 충격량을 물리 계산 간격으로 나눠 가상 접촉력을 추정합니다. 이 값을 당김 서보의 각도 명령으로 변환합니다.

switch (_state)
        {
            case HapticState.Rotating:
                if (angleDeg <= servo1MaxAngle && dist < pressStartDistance)
                    _state = HapticState.Pressing;
                break;

            case HapticState.Pressing:
                if (dist > pressStopDistance)
                    _state = HapticState.Rotating;
                break;
        }

위 수치는 제어 코드의 설정값입니다. 패드 각도와 손끝에 가해진 힘을 센서로 읽지 않으므로, 상태 전환만으로 실제 패드가 물체 표면과 의도한 각도로 맞닿았는지는 확인할 수 없습니다.

시제품에서 확인한 점

손 추적, 가상 블록과의 상호작용, 서보 구동이 함께 작동하는 것을 확인했습니다. 추적 끊김, 체감 지연, 서보 떨림, 두 구동 경로 간 기계적 간섭은 남았습니다.

미측정 항목 손끝에 전달된 힘, 전체 시스템 지연, 사용자가 느끼는 효과.

담당 범위와 관찰 결과

세 차례 시제품을 제작하고, 손 추적에서 가상 상호작용과 서보 구동까지 이어지는 시스템을 구성했습니다. 상호작용 방식과 기구를 설계하고, 제작과 연동에 필요한 조건을 정리하며 시제품을 반복해서 테스트했습니다. 소프트웨어 일부는 AI의 도움을 받아 초안을 작성했고, 실제 하드웨어에 연결해 테스트하며 수정했습니다.

남은 한계

손 자세에 따라 추적이 끊길 수 있었고, 체감 지연과 서보 떨림, 두 줄 구동부 사이의 간섭이 관찰됐습니다. 손끝에 전달된 힘을 계측하거나, 사용자가 블록 저항의 차이를 구별하는지 평가하지는 않았습니다.

후속 연구 아이디어 · 미구현

시연에서는 손 추적과 가상 상호작용, 서보 구동의 연동을 확인했습니다. 지각 효과는 아직 평가하지 않았으며, 아래는 후속 작업으로 검토할 수 있는 방향입니다.

  • 지연과 변위 측정손동작부터 패드 구동까지 걸리는 시간과 명령한 서보 각도에 따른 패드 변위를 측정합니다.
  • 접촉력 측정과 폐루프 제어힘 또는 압력 센서로 손끝에 전달되는 힘을 측정하고, 그 값을 패드 제어에 반영하는 방식을 검토합니다.
  • 기계적 간섭 완화패드 회전과 당김이 서로 영향을 덜 주도록 구동부를 개선합니다.
  • 지각 평가패드가 전달하는 접촉 단서로 사용자가 블록 저항을 구별할 수 있는지 평가합니다.
  • 촉각 단서 추가지속적으로 당기는 힘과 함께, 접촉 순간을 알리는 진동을 검토합니다.
